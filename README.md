# cardpack (목업 v0.2)

랜덤 카드팩 개봉 로그라이크의 플레이 가능한 목업. 설계는 [DESIGN.md](DESIGN.md), 변경점은 [CHANGELOG.md](CHANGELOG.md).

- 플레이: https://agihuimini.github.io/cardpack/
- 개봉 연출 데모: https://agihuimini.github.io/cardpack/demo/unpack.html
- 로컬 실행: `python3 -m http.server` 후 http://localhost:8000 (빌드 없음)
- 밸런스 시뮬레이션: `node sim/sim.js 500`

## 파일

| 파일 | 내용 |
|------|------|
| `css/unpack.css` | 개봉 연출 공용 스타일 (게임·데모 공용) |
| `js/cards.js` | 등급·마감·마모·데모 카드 20장, 팩 내 능력·가격 계산 (게임·데모·시뮬레이션 공용) |
| `js/unpack.js` | 팩 찢기·뒤집기·계산 연출·정산·3D 자세히 보기 엔진 (게임·데모 공용) |
| `js/data.js` | 본 게임 데이터: 팩, 추가 카드, 특수·이벤트 카드, 컬렉션, 아이템, 해금 — **수치 조정은 여기서** |
| `js/game.js` | 게임 로직 (DOM 없음, Node에서도 동작) |
| `js/storage.js` | localStorage 저장 (전부 try/catch) |
| `js/ui.js` | 화면 |
| `demo/unpack.html` | 승인된 개봉 연출 레퍼런스 (공용 파일 사용) |
| `sim/sim.js` | 봇 시뮬레이션 |

## 설계 해석 (DESIGN.md에 없던 부분)

- **카드 풀**: 데모 20장에 보석·날씨·탈것·악기 4태그 × 5장 추가 → 컬렉션 8개. 바자회 특수카드 5장은 9번째 '바자회' 컬렉션.
- **이벤트 카드** 3종(황금 왕관·우승 트로피·혜성): 카드 1장당 0.05% × 팩 boost 판정, 한 판에 각 1장.
- **미개봉 팩**은 다음 날로 넘어감 (지불은 개봉 중만 아니면 가능).
- **판매 배율**: 확정 가격 × (1 + 판매가 효과) × (바자회면 등급 프리미엄). 바자회 프리미엄: 일반 1 / 브론즈 1.1 / 실버 1.2 / 골드 1.4 / 플래티넘 1.6 / 다이아 1.8 / 레어 2 / 에픽 2.4 / 레전드·이벤트 3.
- **컬렉션 효과**: 과일 모든 가치 +15% · 행성 골드 이상 확률 +25% · 동물 마모 2번 굴림 · 무기 판매가 +15% · 보석 마감 확률 +75% · 날씨 아침 +15원 · 탈것 팩 가격 −20% · 악기 바자회 프리미엄 +0.5 · 바자회 하루 팩 +1. 효과 보정(가치 +%)은 개봉 시점에 카드 가격에 반영되어 확정됨.
- **묶음 판매**: 종류별로 가장 싼 1장씩 5장, 개별 판매가 합계 ×2.
- **상인**: 수집가(특정 태그 보관함 카드를 바자회 시세 ×1.5에 매입, 3장), 행상인(카드 3장 판매), 교환상(같은 등급 2장 → 한 등급 위 1장, 2회).
- **진열장 확장**은 바자회 아이템 코너에서 사며 칸을 차지하지 않음. 진열품은 반값에 처분 가능.
- **개봉 화면**: 정산 단계에서 [정산 내역] 버튼으로 카드별 가격·적용 능력 목록을 열 수 있음 (카드 위를 가리지 않도록 기본은 닫힘).
