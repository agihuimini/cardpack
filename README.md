# cardpack (목업 v0.3)

랜덤 카드팩 개봉 로그라이크의 플레이 가능한 목업. 설계는 [DESIGN.md](DESIGN.md), 변경점은 [CHANGELOG.md](CHANGELOG.md).

- 플레이: https://agihuimini.github.io/cardpack/
- 개봉 연출 데모: https://agihuimini.github.io/cardpack/demo/unpack.html
- 로컬 실행: `python3 -m http.server` 후 http://localhost:8000 (빌드 없음)
- 밸런스 시뮬레이션: `node sim/sim.js 500`

## 파일

| 파일 | 내용 |
|------|------|
| `css/unpack.css` | 개봉 연출 공용 스타일 (게임·데모 공용) |
| `js/cards.js` | 등급·마감·마모·데모 카드 20장, 팩 내 능력·가격 계산 (게임·데모·시뮬레이션 공용) |
| `js/unpack.js` | 팩 찢기·뒤집기·계산 연출·정산·3D 자세히 보기 엔진 (게임·데모 공용) |
| `js/data.js` | 본 게임 데이터: 일정·대회, 등급·마감 확률, 팩·특수 팩, 추가 카드, 도감 배열, 아이템·업그레이드, 해금 — **수치 조정은 여기서** |
| `js/game.js` | 게임 로직 (DOM 없음, Node에서도 동작) |
| `js/storage.js` | localStorage 저장 (전부 try/catch) |
| `js/ui.js` | 화면 |
| `demo/unpack.html` | 승인된 개봉 연출 레퍼런스 (공용 파일 사용) |
| `sim/sim.js` | 봇 시뮬레이션 |

## 설계 해석 (DESIGN.md에 없거나 가안인 부분)

- **카드 풀**: 데모 20장에 보석·날씨·탈것·악기 4분류 × 5장 추가. 바자회 특수카드 5장, 이벤트 카드 3종(황금 왕관·우승 트로피·혜성).
- **바자회 단계**: 3·6일차 할당량 지불 후 같은 날짜에서 열림. 특수팩(하루 팩 한도와 별도)·단품·상인·업그레이드. [바자회 마치고 다음 날로]로 종료.
- **대회**: 대회팩 3개(골드 이상 ×2)는 무료. 점수 = 팩 정산 합계 × 전체 점수 배율 (판매/도감 선택과 무관). 미개봉 일반 팩은 대회 날에도 열 수 있지만 점수에 안 들어감.
- **도감**: 판매에서 제외한 카드·바자회에서 산 카드는 일반카드(임시) 칸으로. [임시칸 → 지정칸 자동 정리]는 빈 지정칸만 채움(같은 카드가 여럿이면 비싼 것). 교환상은 일반카드 칸의 카드만 사용.
- **판매 배율**: 확정 가격 × 전체 점수(가로줄) × (1 + 판매가 효과) × (바자회면 등급 프리미엄).
- **분류 행운**: 카드 종류를 먼저 정한 뒤 그 분류의 골드 이상 확률을 올려 등급을 굴림 (분류 팩 모음과 겹치면 효과 큼).
- **진열품 처분**은 반값. 진열장 확장은 칸을 차지하지 않음.
