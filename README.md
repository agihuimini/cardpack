# cardpack (목업)

랜덤 카드팩 개봉 로그라이크의 플레이 가능한 목업. 설계는 [DESIGN.md](DESIGN.md).

- 플레이: https://agihuimini.github.io/cardpack/
- 로컬 실행: `python3 -m http.server` 후 http://localhost:8000 (빌드 없음)
- 밸런스 시뮬레이션: `node sim/sim.js 2000`

## 파일

| 파일 | 내용 |
|------|------|
| `js/data.js` | 카드 40장 + 특수카드 6장, 팩, 아이템, 세트 효과, NPC, 해금 — **수치 조정은 여기서** |
| `js/game.js` | 게임 로직(DOM 없음, Node에서도 동작) |
| `js/storage.js` | localStorage 저장(전부 try/catch) |
| `js/ui.js` | 텍스트/박스/버튼 화면 |
| `sim/sim.js` | 봇 시뮬레이션 |

## 설계 해석 (DESIGN.md에 없던 부분)

- **카드**: 8세트(과일·동물·보석·날씨·음식·탈것·우주·악기) × C/B/A/S/SS 1장씩. 개봉은 희귀도를 먼저 뽑고 그 희귀도 카드 중 균등 추첨.
- **세트 효과**: 서로 다른 카드 3장 보관 → 1단계, 5장 → 2단계(세트 보너스 + 보관 카드 가치 +50%). 특수카드 '무지개 카드'는 모든 세트에 1장으로 계산.
- **가치 계산**: 기본가 × (1 + 모든가치% + 희귀도% + 세트%) × 판매가배율 × (바자회면 프리미엄) × (보관 카드면 보관가치배율).
- **바자회 날**: 일반 팩(기본/실버/골드)도 함께 판매. 아이템은 안 나옴. 특수팩(9장 중 1장 특수카드, 하루 2개 한정), 특수카드 단품 2장, NPC 3명(수집가·행상인·교환상·점쟁이 중 랜덤).
- **팩 구매**는 지불 전까지 언제든 가능(하루 최대 5개). 팩을 열어 판 돈으로 더 살 수 있음.
- **실버/골드 등장 조건** "보유금 ≥ 150/400"은 그날 한 번이라도 도달하면 그날 내내 등장.
- **앨범**: 목격 = 개봉·진열에서 봄, 수집 = 보관한 적 있음. 세트 '완성' = 5장 모두 수집.
- **해금**: 5일 생존 → 실버 상시, 7일 → 골든 티켓, 10일 → 골드 상시, 앨범 30% → 탐험가 지도, 60% → 프리미엄 특수팩, 세트 완성 → 그 세트 컬렉션 북(세트 가치 +100%).
- **저장**: 모든 행동 후 자동 저장(이어하기 슬롯 1개). 게임 오버 시 슬롯 삭제.

## 밸런스 (2000판 시뮬레이션)

DESIGN.md 수치(시작자금·팩·할당량·바자회 프리미엄)는 그대로 두고, 직접 만든 카드/아이템 효과만 조정함.

| 봇 | 생존 중앙값 | 1일 | 3일 | 5일 | 10일 |
|----|-----|-----|-----|-----|-----|
| 전부 판매(보관 안 함, 기본팩만) | 6일 | 100% | 91% | 68% | 0% |
| 탐욕(A 이상 보관, 아이템 구매, 최적 팩 조합) | 19일 | 100% | 93% | 80% | 68% |

- 초반(1~3일)은 너무 쉽지도 어렵지도 않음: 1일차는 사실상 통과, 3일까지 ~7% 탈락(순수 운).
- **중반이 쉬움**: 6·9일차 바자회(골드팩 + SS ×3)에서 돈이 크게 불어 이후 10일 가까이 여유가 생김.
  할당량 증가율만 바꿨을 때 탐욕 봇 생존 중앙값: 1.3 → 19일, **1.35 → 13일**, 1.4 → 9일, 1.45 → 7일. 플레이테스트 후 1.35 정도를 검토할 만함.
- 효과를 낮추기 전에는 SS 카드(황금사과·블랙홀·용·로켓)와 '큰 장바구니' 중첩 때문에 중앙값이 22일까지 갔음 → SS 효과 하향, 큰 장바구니·감정사 자격증 중첩 불가, 이자 상한 50.
- 함정: 일반 날엔 실버(+10.6/팩)·골드(−8/팩)가 기본팩(+13/팩)보다 손해. 상위 팩은 바자회 날이나 효과가 쌓였을 때 이득. 팩 버튼에 기대가치를 표시해 둠.
